This is iHOMIS Plus extension develop by "ME".
The purpose of this extension is to generate some reports that is not available yet in the system.
While waiting for the updates of iHOMIS Plus, we decide to create extension since it is needed, mandatory and required for the facility/hospitals.
The extension only pulling out some data and does not "MODIFY" the database, tables, columns nor the data and make it into reports files (such as excel, print, csv)
Note: This is only temporary. Once the report are now available in the iHOMIS Plus, the module will be removed from the user so that the iHOMIS Plus will be fully utilized.
